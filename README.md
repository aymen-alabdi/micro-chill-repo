Each entrant writes one line of horror: a single sentence of under 200 characters that has to frighten a reader in one breath. No setup, no paragraph, no second chance. A judge model reads the lines two at a time and asks which one is scarier, weighing how frightening it is first, then how vivid, then how original, then how well the sentence is built. The lines that win the most comparisons take the top places.

## Run it

```sh
mkdir -p /output && node main.ts
```
